# Elqo — Learner Home Dashboard

Static, high-fidelity mockup of the Elqo learner home dashboard. Desktop-first (1440px), mock data only — no backend.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4 (brand tokens as CSS variables + `@theme`)
- lucide-react icons

## Run locally

```bash
npm install
npm run dev
```

Dev server binds to `0.0.0.0:43141` → [http://127.0.0.1:43141](http://127.0.0.1:43141)

## Brand notes

- Neutrals carry the UI; Forsythia gold is limited to one primary CTA and small achievement moments (streak flame, El mark).
- Moss / Clay are data-layer only (score chips, status flags).
- Wordmark uses `--font-wordmark` (Fraunces stand-in for Lastik — one-line swap when Lastik is available).
